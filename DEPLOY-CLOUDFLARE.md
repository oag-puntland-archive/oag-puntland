# Cloudflare Pages — one-time setup (≈5 minutes)

The repo is already pushed to GitHub at `oag-puntland-archive/oag-puntland`. This walkthrough connects it to Cloudflare Pages for auto-deploy on every push.

---

## Steps

1. **Sign in** to https://dash.cloudflare.com (create a free account if needed).
2. Left sidebar: **Workers & Pages** → **Create application** → **Pages** tab → **Connect to Git**.
3. **Authorize Cloudflare** to access GitHub. When prompted, grant access to the org `oag-puntland-archive` (or "all repos" if you're not particular).
4. Pick the repository: **`oag-puntland-archive/oag-puntland`** → **Begin setup**.
5. **Project name:** `oag-puntland` _(this becomes the subdomain — `oag-puntland.pages.dev`)_.
6. **Production branch:** `main`.
7. **Build settings:**
   - **Framework preset:** Astro _(if listed; otherwise None — the build command below is sufficient)_.
   - **Build command:** `cd site && pnpm run build`
   - **Build output directory:** `site/dist`
   - **Root directory:** leave blank (project root).
8. **Environment variables (build & preview):**
   - `NODE_VERSION` = `20`
   - `SOURCE_DATE_EPOCH` = `1717344000` _(deterministic build timestamp; matches local + CI for reproducibility)_
   - **No mirror URL env vars needed.** `governance/mirrors.json` (committed) is the source of truth.
9. **Save and Deploy.**
10. Wait ≈2 min. The build will run `cd site && pnpm run build` which chains `ingest → astro build → strip-build-paths` and emits `site/dist`. When the build completes you'll see a green "Success" with a live URL of the form `https://oag-puntland.pages.dev`.

## What this does NOT need

- ❌ A custom domain. v1 lives on `oag-puntland.pages.dev`. Custom domain (e.g. `oag-puntland.org`) is post-v1 work.
- ❌ Cloudflare Workers / Functions. Static-only.
- ❌ Cloudflare Access / authentication. Public.
- ❌ Cloudflare Analytics. Privacy-by-deletion (doctrine §6).

## Auto-redeploys

Once connected, every push to `main` on the GitHub mirror auto-triggers a CF Pages rebuild. No further user action needed for ordinary content updates.
